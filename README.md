# Insansu Venture website

Static site (HTML, CSS, a little JS) for https://insansuventure.online — no build step.

- Pages: `index.html`, `about.html`, `products.html`, `projects.html`, `contact.html`
- Styles: `css/style.css` · Script: `js/main.js`
- Images: `images/brand`, `images/crops`, `images/products`, `images/team` · Video: `videos/`
- Hosted with GitHub Pages; custom domain set in the `CNAME` file.
