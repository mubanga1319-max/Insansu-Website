# Insansu inbox

Drop new photos and videos for the website in this folder.
Then message Claude: "check the inbox".

## How to upload (phone or computer)
1. Open github.com/mubanga1319-max/Insansu-Website
2. Open the `inbox` folder
3. Click **Add file → Upload files**, drop your photos, and click **Commit changes**

## Tell Claude what each one is
Name the file so it says what it is, or put the details in your message:
- `news-nursery-first-seedlings.jpg` → goes on the News page
- `field-new-planting.jpg` → goes on the Products page (Growing today)
- `product-peanut-butter.jpg` → replaces or adds a product photo
- `team-...jpg` → About page

Add a short caption and the date in your message to Claude, e.g.
"News, 20 Oct 2026: first onion transplants went into the field."

## Tips
- Use JPG or PNG. HEIC photos (some iPhones and Samsung phones) cannot be read.
  On Samsung turn off "High efficiency pictures"; on iPhone use Settings → Camera → Formats → Most Compatible.
- Videos: MP4, under 50 MB if possible.
- Anything in this folder can be seen publicly until Claude moves it out. Only upload photos you are happy to show.
